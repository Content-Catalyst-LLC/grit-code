# Grit-Supportive Design Checklist

## Article

**Designing Environments That Support Grit**

Use this checklist for synthetic program design, article support, teaching, and professional reflection. It is not an assessment instrument.

## Autonomy

- [ ] Goals are explained, not merely imposed.
- [ ] People have voice in methods or pathways where possible.
- [ ] People can ask why the work matters.
- [ ] Effort is connected to values, contribution, or purpose.

## Competence

- [ ] Standards are clear.
- [ ] Feedback is specific and actionable.
- [ ] Practice is structured.
- [ ] Revision is expected.
- [ ] Progress is visible.

## Belonging

- [ ] Struggle is normalized.
- [ ] Mentoring is available.
- [ ] Peer support is structured.
- [ ] People see themselves as legitimate participants.
- [ ] Exclusion is addressed rather than reframed as mindset.

## Psychological safety

- [ ] Questions are welcomed.
- [ ] Mistakes can be discussed.
- [ ] Correction protects dignity.
- [ ] Help-seeking is not punished.
- [ ] Leaders model learning.

## Recovery

- [ ] Workload is realistic.
- [ ] Rest is protected.
- [ ] Recovery after setbacks is supported.
- [ ] Health needs are taken seriously.
- [ ] Burnout risk is monitored.

## Resources

- [ ] People have required tools.
- [ ] Time demands are feasible.
- [ ] Accessibility needs are addressed.
- [ ] Care responsibilities are considered.
- [ ] Material barriers are identified.

## Fairness

- [ ] Evaluation criteria are transparent.
- [ ] Bias is monitored.
- [ ] Pathways are credible.
- [ ] Opportunities are distributed fairly.
- [ ] Support is not available only to insiders.

## Adaptive revision

- [ ] Strategy revision is normalized.
- [ ] Goal review is built in.
- [ ] Adaptive quitting is not shamed.
- [ ] Exit pathways preserve dignity.
- [ ] Persistence is not glorified when harmful.
