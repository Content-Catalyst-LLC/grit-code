# Grit and Self-Control: Related but Not the Same

This article folder supports reproducible research examples for **Grit and Self-Control: Related but Not the Same** in the Grit knowledge series.

The workflows use synthetic data to demonstrate how grit and self-control can be modeled as related but separable constructs:

- self-control
- attention regulation
- emotion regulation
- impulse control
- perseverance of effort
- consistency of interests
- grit
- conscientiousness
- social support
- prior achievement
- burnout
- daily task completion
- long-term goal progress

## Repository purpose

This scaffold is designed for article support, reproducible learning, research-method demonstration, and transparent computational examples. It is not designed for ranking, hiring, admissions, discipline, psychological diagnosis, or evaluation of real people.

## Folder structure

- `python/` — Python workflow for modeling grit and self-control separately
- `r/` — R workflow for profiles, outcomes, and contextual controls
- `julia/` — Julia synthetic-data sketch
- `sql/` — SQL schema and analytical views
- `c/`, `cpp/`, `fortran/`, `go/`, `rust/` — compact computational examples
- `data/raw/` — small synthetic example dataset
- `data/processed/` — generated modeled datasets
- `docs/` — methods note, responsible-use note, and WordPress GitHub embed block
- `notebooks/` — notebook planning notes
- `outputs/figures/` — generated figures
- `outputs/tables/` — generated tables

## Responsible use

These workflows use synthetic data. They should not be used to assess, score, select, discipline, hire, promote, or psychologically evaluate real individuals.
