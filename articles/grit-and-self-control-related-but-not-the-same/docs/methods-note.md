# Methods Note

This article folder demonstrates the distinction between self-control and grit.

Self-control is modeled as short-term regulation:

\[
SC_i = f(R_i, A_i, E_i, T_i)
\]

where \(SC_i\) represents self-control, \(R_i\) regulation capacity, \(A_i\) attention, \(E_i\) emotional state, and \(T_i\) temptation intensity.

Grit is modeled as long-term goal pursuit:

\[
G_i = w_P P_i + w_C C_i
\]

where \(G_i\) represents grit, \(P_i\) perseverance of effort, and \(C_i\) consistency of interests.

A broader outcome model can include both constructs:

\[
Y_i = \beta_0 + \beta_1SC_i + \beta_2G_i + \beta_3K_i + \beta_4S_i + \epsilon_i
\]

where \(Y_i\) is a task-completion, persistence, or long-term progress outcome; \(K_i\) is a related construct such as conscientiousness or prior achievement; and \(S_i\) is social support or context.

The core methodological point is that self-control and grit are correlated but separable. Self-control may matter more for daily task completion, while grit may matter more for long-term goal progress.
