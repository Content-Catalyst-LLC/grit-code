# When Quitting Is Adaptive

This article folder supports reproducible research examples for **When Quitting Is Adaptive** in the Grit knowledge series.

The workflows use synthetic data to demonstrate adaptive quitting as goal disengagement plus possible reengagement, rather than as the simple absence of grit:

- perseverance of effort
- consistency of interests
- grit
- cumulative cost
- health risk
- goal misalignment
- opportunity cost
- future value
- learning potential
- purpose alignment
- social support
- financial security
- feedback responsiveness
- sunk cost
- identity pressure
- alternative goal value
- quitting pressure
- overpersistence risk
- adaptive quitting readiness
- sustainable persistence
- responsible interpretation

## Repository purpose

This scaffold is designed for article support, reproducible learning, research-method demonstration, and transparent computational examples. It is not designed for ranking, admissions, hiring, discipline, psychological diagnosis, student evaluation, employee evaluation, or assessment of real people.

## Folder structure

- `python/` — Python workflow for modeling adaptive quitting and redirection
- `r/` — R workflow for goal disengagement, reengagement, and sustainable persistence
- `julia/` — Julia synthetic-data sketch
- `sql/` — SQL schema and analytical views
- `c/`, `cpp/`, `fortran/`, `go/`, `rust/` — compact computational examples
- `data/raw/` — small synthetic example dataset
- `data/processed/` — generated modeled datasets
- `docs/` — methods note, responsible-use note, and WordPress GitHub embed block
- `notebooks/` — notebook planning notes
- `outputs/figures/` — generated figures
- `outputs/tables/` — generated tables

## Responsible use

These workflows use synthetic data. They should not be used to assess, score, select, admit, discipline, rank, hire, promote, or psychologically evaluate real people.

The examples are intended to clarify that quitting can be adaptive when continued effort has become harmful, futile, misaligned, or ethically compromised, especially when meaningful alternatives and transition support are available.
