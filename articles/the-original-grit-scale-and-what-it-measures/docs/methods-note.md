# Methods Note

This article folder demonstrates how the Original Grit Scale can be represented as a measurement structure with two main facets:

\[
G_i = w_P P_i + w_C C_i
\]

where \(G_i\) is grit, \(P_i\) is perseverance of effort, and \(C_i\) is consistency of interest.

A basic observed-score model can be written as:

\[
X_i = T_i + e_i
\]

where \(X_i\) is the observed grit score, \(T_i\) is the trait-relevant score, and \(e_i\) is measurement error.

A contextual outcome model can be written as:

\[
Y_i = \beta_0 + \beta_1G_i + \beta_2A_i + \beta_3K_i + \beta_4S_i + \epsilon_i
\]

where \(Y_i\) is an outcome, \(A_i\) is prior achievement or ability, \(K_i\) is a related construct such as conscientiousness, and \(S_i\) is support or context.

The workflows use synthetic data and do not reproduce copyrighted scale items.
