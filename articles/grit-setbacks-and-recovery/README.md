# Grit, Setbacks, and Recovery

This article folder supports reproducible research examples for **Grit, Setbacks, and Recovery** in the Grit knowledge series.

The workflows use synthetic data to demonstrate how adaptive persistence after setbacks can be modeled as a recovery system rather than as grit alone:

- perseverance of effort
- consistency of interests
- grit
- setback severity
- emotional recovery
- cognitive recovery
- physical restoration
- social support
- practical resources
- feedback quality
- opportunity access
- recovery capacity
- burnout
- adaptive persistence
- recovery profiles
- responsible interpretation

## Repository purpose

This scaffold is designed for article support, reproducible learning, research-method demonstration, and transparent computational examples. It is not designed for ranking, admissions, hiring, discipline, psychological diagnosis, student evaluation, employee evaluation, or assessment of real people.

## Folder structure

- `python/` — Python workflow for modeling grit, setbacks, and recovery
- `r/` — R workflow for recovery profiles and adaptive persistence
- `julia/` — Julia synthetic-data sketch
- `sql/` — SQL schema and analytical views
- `c/`, `cpp/`, `fortran/`, `go/`, `rust/` — compact computational examples
- `data/raw/` — small synthetic example dataset
- `data/processed/` — generated modeled datasets
- `docs/` — methods note, responsible-use note, and WordPress GitHub embed block
- `notebooks/` — notebook planning notes
- `outputs/figures/` — generated figures
- `outputs/tables/` — generated tables

## Responsible use

These workflows use synthetic data. They should not be used to assess, score, select, admit, discipline, rank, hire, promote, or psychologically evaluate real people.

The examples are intended to clarify how persistence after setbacks depends on grit, but also on recovery capacity, support, feedback, opportunity, resources, rest, burnout risk, and the severity of disruption.
