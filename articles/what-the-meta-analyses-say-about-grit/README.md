# What the Meta-Analyses Say About Grit

This article folder supports reproducible research examples for **What the Meta-Analyses Say About Grit** in the Grit knowledge series.

The workflows use synthetic study-level data to demonstrate basic meta-analytic ideas relevant to grit research:

- pooled correlations
- Fisher's z transformation
- fixed-effect and random-effects synthesis
- perseverance of effort versus consistency of interests
- total grit versus facet-level interpretation
- heterogeneity
- effect-size interpretation
- measurement limits
- responsible evidence synthesis

## Repository purpose

This scaffold is designed for article support, reproducible learning, research-method demonstration, and transparent computational examples. It is not a substitute for a real systematic review or meta-analysis.

## Folder structure

- `python/` — Python workflow for simulating grit meta-analysis
- `r/` — R workflow for random-effects synthesis of synthetic correlations
- `julia/` — Julia synthetic meta-analysis sketch
- `sql/` — SQL schema and analytical views for study-level synthetic data
- `c/`, `cpp/`, `fortran/`, `go/`, `rust/` — compact computational examples
- `data/raw/` — small synthetic example study-level dataset
- `data/processed/` — generated modeled datasets
- `docs/` — methods note, responsible-use note, and WordPress GitHub embed block
- `notebooks/` — notebook planning notes
- `outputs/figures/` — generated figures
- `outputs/tables/` — generated tables

## Responsible use

These workflows use synthetic data for educational demonstration. They should not be used as substitutes for a real meta-analysis, systematic literature search, risk-of-bias assessment, publication-bias analysis, preregistered review protocol, or domain expert judgment.
