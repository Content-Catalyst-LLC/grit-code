# Responsible Use Note

These files use synthetic data and are intended for article support, reproducible research education, and methodological demonstration.

They should not be used as substitutes for:

- a systematic review protocol
- real database searches
- inclusion/exclusion screening
- study coding by multiple reviewers
- risk-of-bias assessment
- publication-bias analysis
- moderator analysis based on real study characteristics
- domain expert judgment
- policy or clinical decision-making

The workflows demonstrate how pooled correlations can be estimated. They do not claim to reproduce actual published grit meta-analytic results.
