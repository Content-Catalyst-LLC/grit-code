# Methods Note

This folder models grit as a developmental process rather than as a fixed character label.

A simple longitudinal model can represent grit at time \(t+1\) as a function of prior grit, practice, support, feedback, purpose, recovery, opportunity, and chronic stress:

\[
G_{i,t+1} = \rho G_{i,t} + \alpha P_{i,t} + \beta S_{i,t} + \gamma F_{i,t} + \delta U_{i,t} + \theta R_{i,t} + \lambda O_{i,t} - \kappa K_{i,t} + \epsilon_{i,t}
\]

Perseverance of effort and consistency of interests can be modeled separately:

\[
G_{i,t} = w_EE_{i,t} + w_CC_{i,t}
\]

The purpose is to demonstrate how developmental stage, support, feedback, purpose, recovery, opportunity, and stress can shape grit trajectories across adolescence and adulthood.
