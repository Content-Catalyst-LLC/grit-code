# Methods Note

This article folder demonstrates how grit can be modeled as one contributor to academic persistence rather than as a stand-alone explanation.

A simple academic persistence model can include grit, self-control, belonging, instructional quality, support, and burnout:

\[
P_i = \beta_0 + \beta_1G_i + \beta_2SC_i + \beta_3B_i + \beta_4I_i + \beta_5S_i - \beta_6R_i + \epsilon_i
\]

where \(P_i\) is academic persistence, \(G_i\) is grit, \(SC_i\) is self-control, \(B_i\) is belonging, \(I_i\) is instructional quality, \(S_i\) is support, and \(R_i\) is burnout or strain.

A progress model can represent learning over time:

\[
Y_{t+1} = Y_t + \lambda E_t + \phi F_t + \sigma S_t + \omega B_t - \delta R_t + \eta_t
\]

where future academic progress depends on prior progress, study effort, feedback, support, belonging, burnout, and changing life conditions.

A study-effort model can represent one pathway through which grit may influence persistence:

\[
E_t = \alpha_0 + \alpha_1G_t + \alpha_2M_t + \alpha_3C_t - \alpha_4R_t + u_t
\]

The workflows use synthetic data to show that academic persistence depends on grit and self-control, but also on prior preparation, instructional quality, feedback, belonging, support, financial stress, health, burnout, and academic progress.
