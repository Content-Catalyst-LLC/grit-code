# Grit and Academic Persistence

This article folder supports reproducible research examples for **Grit and Academic Persistence** in the Grit knowledge series.

The workflows use synthetic data to demonstrate how academic persistence can be modeled as a developmental system rather than as a grit-only outcome:

- perseverance of effort
- consistency of interests
- grit
- self-control
- study effort
- prior preparation
- instructional quality
- feedback quality
- belonging
- social support
- financial stress
- health stability
- burnout
- academic progress
- academic persistence
- retention and completion interpretation

## Repository purpose

This scaffold is designed for article support, reproducible learning, research-method demonstration, and transparent computational examples. It is not designed for ranking, admissions, discipline, psychological diagnosis, employee evaluation, student evaluation, or assessment of real people.

## Folder structure

- `python/` — Python workflow for modeling grit and academic persistence
- `r/` — R workflow for persistence, belonging, support, and academic progress
- `julia/` — Julia synthetic-data sketch
- `sql/` — SQL schema and analytical views
- `c/`, `cpp/`, `fortran/`, `go/`, `rust/` — compact computational examples
- `data/raw/` — small synthetic example dataset
- `data/processed/` — generated modeled datasets
- `docs/` — methods note, responsible-use note, and WordPress GitHub embed block
- `notebooks/` — notebook planning notes
- `outputs/figures/` — generated figures
- `outputs/tables/` — generated tables

## Responsible use

These workflows use synthetic data. They should not be used to assess, score, select, admit, discipline, rank, or psychologically evaluate real students.

The examples are intended to clarify how academic persistence depends on student effort and self-regulation, but also on instruction, feedback, belonging, social support, financial stress, health, burnout, and institutional conditions.
