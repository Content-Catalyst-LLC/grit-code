# Angela Duckworth and the Modern Science of Grit

This article folder supports reproducible research examples for **Angela Duckworth and the Modern Science of Grit** in the Grit knowledge series.

The examples use synthetic data to demonstrate how grit can be modeled as a two-facet construct while accounting for related psychological and contextual variables:

- perseverance of effort
- consistency of interest
- self-control
- conscientiousness
- social support
- prior achievement
- achievement-related outcomes

## Repository purpose

This scaffold is designed for article support, reproducible learning, research-method demonstration, and transparent computational examples. It is not designed for ranking, hiring, admissions, discipline, psychological diagnosis, or evaluation of real people.

## Folder structure

- `python/` — Python workflow for synthetic grit modeling
- `r/` — R workflow for regression comparison
- `julia/` — Julia synthetic-data sketch
- `sql/` — SQL schema and example analytical view
- `c/`, `cpp/`, `fortran/`, `go/`, `rust/` — compact computational examples
- `data/raw/` — small synthetic example dataset
- `data/processed/` — generated modeled datasets
- `docs/` — methods note, responsible-use note, and WordPress GitHub embed block
- `notebooks/` — notebook planning notes
- `outputs/figures/` — generated figures
- `outputs/tables/` — generated tables

## Responsible use

These workflows are for synthetic-data demonstration and research education. They should not be used to assess, score, select, discipline, hire, promote, or psychologically evaluate real individuals.
